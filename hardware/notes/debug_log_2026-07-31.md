# 板级异常 Debug Log（2026-07-30～2026-07-31）

本文记录当前 TJC8048X270_11 板级镜像的两轮实测异常、已知事实、初步推理和下一轮
只读抓取方案。本文是问题记录，不代表已经定位根因；本轮没有修改 RTL、XDC、IP
或 bitstream。

## 1. 当前测试基线

- FPGA：Mizar Z7 / `xc7z020clg400-2`
- ADC：ADS6149，14 bit，200 MSPS
- 数字链路：200 MSPS → `/10` → 20 MSPS FIR → `/10` → 2 MSPS
- FFT：4096 点、Hann、自然顺序、block floating point
- FFT 帧长：`4096/2 MHz=2.048 ms`
- 频率间隔：`2 MHz/4096=488.28125 Hz`
- 信号源和电缆：50 Ω 条件
- 校准：100 kHz、200 mVpp 单音，连续平均 16 帧
- 屏幕数值：Um 为正弦峰值，不是 Vpp

## 2. 异常 A：弱基波在多谐波输入中偏大

### 2.1 输入和现象

第一组输入：

| 分量 | 信号源 Vpp | 理论 Um | 相位 |
|---|---:|---:|---:|
| 基波 | 50 mV | 25 mV | 100° |
| 2 次谐波 | 200 mV | 100 mV | 40° |
| 4 次谐波 | 250 mV | 125 mV | 0° |

现象：

- 基波频率基本正确；
- 基波 Um 测得约 30 mV，理论值为 25 mV，偏大约 5 mV/20%；
- 去掉各分量相位差后，基波幅值仍可能存在偏差；
- 随后先给一个较大幅值的 200 mV 正弦，再返回
  `50+200+250 mVpp`、零相位组合，有时又能测准。

### 2.2 已排除或暂不支持的解释

相位本身不应改变理想 FFT 的复数模长：

```text
|X[k]| = sqrt(Re[k]^2+Im[k]^2)
```

只要各频率可分辨、ADC 未饱和且采样帧稳定，相位只改变 Re/Im 的比例。使用当前
Hann 三点公式对 10～125 kHz 基波范围、`Um=25/100/125 mV` 和
`100°/40°/0°` 进行离线数值复算，基波幅值变化远小于 1%，不能解释约 20% 偏差。

FPGA 也没有“输入大信号后自动学习”的数据通路。能持续改变电压比例的只有
`active_gain_q16`，它只会在复位、合法 `gain_write` 或收到 `C/0x43` 并成功完成
校准时改变。板级顶层把 `gain_write` 固定为 0。

### 2.3 当前优先怀疑

1. 信号源谐波/ARB 波形编辑后，输出数据没有立即刷新为预期波形；
2. 改变信号源参数后过早按 R19，屏幕锁存了过渡 FFT 帧；
3. 意外收到 `C/0x43`，导致增益重新校准；若如此，三个分量应按同一比例变化；
4. ADC 返回时钟采集裕量不足或源/ADC 非线性，使强谐波条件下产生确定性杂散；
5. 当前频谱自检没有覆盖“弱基波 + 两个更强谐波 + 连续改频/改相位”的历史序列。

## 3. 异常 B：500 kHz 单音被拆成 400 kHz 和 500 kHz

### 3.1 可正常出现的结果

信号源：

```text
500 kHz / 200 mVpp / 50 Ω / 单正弦
```

一次相对正常的屏幕结果：

```text
频率 = 499.684 kHz
Um   = 104 mV
```

理论值为：

```text
f    = 500.000 kHz
Um   = 100 mV
Vrms = 70.711 mV
```

频率误差为 `-316 Hz`，仍在题目 `±1 kHz` 范围内；Um 偏差为 `+4 mV`，仍在
`±5 mV` 边界内，但其重复性需要继续检查。

500 kHz 时，20 MSPS 时域显示每周期只有：

```text
20 MHz/500 kHz = 40 samples/period
```

当前显示模块把约 40 个原始点用最近邻地址扩展到 800 个屏幕点，因此每个原始
采样值会横向重复约 20 个像素，肉眼看到明显阶梯是显示重采样方式造成的预期现象，
不能单独据此判断 ADC 采样失真。

### 3.2 校准后出现的异常结果

刚完成校准后，把信号源设置为同样的
`500 kHz/200 mVpp/50 Ω`，屏幕却显示两个分量：

```text
分量 0：399.988 kHz / Um=92 mV
分量 1：500.000 kHz / Um=8 mV
整体 Vpp：200 mV
整体 Vrms：65 mV
```

数值内部完全自洽：

```text
92 mV + 8 mV = 100 mV = 200 mVpp/2
sqrt((92^2+8^2)/2) = 65.30 mV ≈ 65 mV
```

整体 Vpp 来自 20 MSPS 时域 `max-min`，仍为 200 mV，说明 ADC 看到的瞬时电压
范围没有明显改变。频谱却把总峰值约 100 mV 分配到了 400 kHz 和 500 kHz。

### 3.3 最符合现象的解释：捕获了非稳态改频帧

目前最强的解释不是“稳定 500 kHz 被 FFT 随机拆分”，而是一个 2.048 ms FFT
帧跨越了信号源的改频过程：

```text
帧前段：约 400 kHz
帧后段：500 kHz
```

Hann 窗会按两个频率分别存在于帧内的时间位置和窗权重分配幅值，因此可能得到
约 92 mV 和 8 mV；二者之和恰好等于原单音的 100 mV 峰值，是这一推断的重要
证据。此时算法把同一单音的不同时段误当成两个同时存在且正交的稳定分量，再用
平方和计算 RMS，便得到错误的 65 mV，而真实稳定单音应为 70.7 mV。

若信号源改频后等待 0.5～1 s、连续多次抓取仍稳定显示 400+500 kHz，则该解释
不成立，需要转向以下方向：

1. 用示波器 FFT 确认信号源端是否确实同时含 400 kHz；
2. 抓 ADC/FIR 原始波形，排查采样码错误或周期性漏样/重复；
3. 抓完整 4096 点频谱，检查 400 kHz 峰是稳定窄峰还是过渡帧的宽谱；
4. 检查 `probe6[9]`、`probe6[14]` 和 FIFO 状态；
5. 核对 200 MHz ADC 返回时钟的板级捕获裕量。

### 3.4 关闭输出改频并等待后仍复现

后续按更严格顺序复测：

```text
关闭信号源通道
设置 500 kHz
等待约 1 s
打开通道
等待约 1 s
连续测量三次
```

结果仍异常：

```text
整体 Vpp：200 mV
分量 0：405.261 kHz / Um=0 mV
分量 1：406.262 kHz / Um=0 mV
分量 2：500.050 kHz / Um=0 mV
```

随后重新执行：

```text
打开通道并定标
关闭通道
设置 500 kHz
打开通道
采集
```

得到：

```text
整体 Vpp：200 mV
整体 Vrms：4 mV
分量 0：81.540 kHz / Um=1 mV
分量 1：418.941 kHz / Um=1 mV
分量 2：499.999 kHz / Um=5 mV
```

这组结果否定了“仅仅抓到一次改频过渡帧”作为完整解释。Vpp 始终约 200 mV，
说明 20 MSPS FIR 后的时域支路仍能看到约 200 mV 的极差；但 FFT 支路中稳定
500 kHz 的相干幅值只剩 0～5 mV，其余能量没有形成正确窄峰，而被摊散到大量
bin 或形成伪局部峰。

校准增益也不是主要原因：整体 Vpp 和各频谱 Um 使用同一个
`active_gain_q16`。若增益缩小约 20 倍，整体 Vpp 也应从 200 mV 变成约 10 mV，
而不是继续保持 200 mV。因此异常边界进一步缩小为：

```text
20 MSPS FIR 输出
    ├─ 时域环形缓存/max-min：Vpp 基本正确
    └─ /10 帧缓存/Hann/FFT/峰搜索：相干频谱严重异常
```

另一种仍需保留的可能是 ADC 并行码捕获不稳定：偶发或码型相关的 bit 错误可以
保留 max/min 极差，却破坏样本序列的相干性，使正弦能量扩散为宽带杂散。当前
ADC `CLKOUT` 使用非专用时钟脚 L20 和 `CLOCK_DEDICATED_ROUTE FALSE`，并且
XDC 中的 `set_input_delay -max -1.000/-min 0.400 ns` 是暂定假设而不是 ADS6149
在 200 MSPS 下的厂家保证值，所以“实现报告时序通过”不能证明真实 ADC 数据眼
采在中心。

下一次必须取得 500 kHz 异常状态下的原始 ADC/FIR 波形和完整频谱，才能在
“ADC 捕获失真”与“帧缓存/FFT 支路失真”之间做最终区分。当前精简 ILA 不含这些
信号，不能只靠屏幕结果下结论。

### 3.5 阶梯状波形与平滑显示

当前波形显示支路使用 FIR 后的 20 MSPS 数据。500 kHz 输入每周期约有

\[
\frac{20\ \mathrm{MSPS}}{500\ \mathrm{kHz}}=40
\]

个真实采样点，但屏幕横向要发送 800 个像素点。现有显示模块按地址选取最接近的原始
采样点，同一个采样值会被重复用于多个相邻像素，所以会看见明显台阶。这是显示重采样
方式造成的，不代表 ADC 只有 40 个像素精度，也不会直接导致 FFT 测频错误。

显示可改为相邻采样点的一阶线性插值：

\[
y=x_0+\frac{\mathrm{frac}}{2^{16}}(x_1-x_0)
\]

其中 `x0`、`x1` 是相邻的 20 MSPS 样点，`frac` 是屏幕横坐标映射到采样地址后的小数
部分。这样仍发送 800 点，但相邻真实样点之间不再简单重复，视觉上会平滑很多。该改动
只作用于串口屏绘图，不应进入测量和 FFT 数据通路。

当前实现后的最差裕量很小，因此线性插值需要采用寄存器流水线，完成后必须重新实现并
检查时序。为避免同时改变显示与测量两个变量，应先定位本节上方记录的 FFT/采集异常，
再合入显示插值。

## 4. 异常 C：频谱模式返回时域模式需要按两次

现象：

- 进入频谱图模式后，第一次点击单周期或三周期按钮，有时看不到时域图；
- 再点击一次后才显示。
- 用户口述中出现“双周期”，当前 RTL/UI 定义实际为“单周期/三周期”，后续记录
  以当前按钮定义为准。

### 4.1 RTL 中存在的潜在请求丢失窗口

`g_tjc_display_uart` 收到 `1/3` 后会同时：

```text
spectrum_mode          <- 0
waveform_render_request <- 单拍
plot_request_pending    <- 1
waveform_refresh_seen   <- 0
```

屏幕发送状态机会等待 `waveform_render_done`，再传送时域图。正常情况下按一次即可。

但是 `g_time_domain_display` 只在忙状态下把 `render_request` 保存到
`pending_render_request`。若请求到达时状态恰好是 `ST_IDLE`，但以下任一条件当拍
不满足，请求会在下一拍消失：

```text
fundamental_frequency_hz 在 10～500 kHz
环形缓存已经填满
测量频率/模式状态已经稳定
```

此时 UART 侧仍保持：

```text
plot_request_pending  = 1
waveform_refresh_seen = 0
```

却再也等不到新的 `waveform_render_done`，第二次按键才会重新产生 render request。
这与“第一次无反应、第二次成功”的现象一致，是当前最值得验证的软件时序假设。

### 4.2 另一个可能因素：波形控件未清屏

当前 FPGA 在切换时域/频谱时直接发送：

```text
addt s0.id,0,800
```

但没有先发送 `cle s0.id,0`。`addt` 的语义是向波形通道追加数据，而 `cle` 才是
清除通道。即使 FPGA 已成功发送第一批时域点，屏幕内部旧频谱数据和写指针状态
也可能让第一次切换看起来没有完整刷新。需要结合 `transfer_done` 和屏幕实际串口
回包区分“FPGA未发送”和“屏幕追加后未清屏”。

## 5. 下一轮不改代码的判别步骤

### 5.1 固定 500 kHz 重复性

1. 校准结束后等待 1 s；
2. 将信号源输出关闭；
3. 设置并确认 `500 kHz/200 mVpp/50 Ω`；
4. 打开输出，再等待 1 s；
5. 连续按 R19 三次，每次间隔至少 1 s；
6. 记录三个分量、Vpp、RMS 和 `probe6`。

若三次均为单个约 500 kHz，原 400+500 kHz 是过渡帧；若持续为双峰，则需要抓
完整旧版频谱 ILA 或示波器 FFT。

### 5.2 分辨“校准系数变化”和“频谱幅值变化”

- 三个 Um 同比例偏差：优先检查 `active_gain_q16`/误校准/信号源总幅度；
- 只有最弱分量偏差：优先检查信号源合成、杂散、非线性或峰值估计；
- Vpp 正确而频谱分量和 RMS 错：优先检查非稳态 FFT 帧或频谱链；
- Vpp、所有 Um 都同比例错误：优先检查增益和 50 Ω 设置。

### 5.3 显示模式按键

从频谱模式返回单周期时，分别记录：

1. 第一次按键后 `probe6[12]` 是否立即从 1 变 0；
2. 是否出现 `probe6[7]`（传输完成）；
3. `probe6[8]` 是否置位（FE/FD 超时）；
4. `probe6[9]` 是否置位（请求 overrun 等汇总错误）；
5. 若 `[7]=1` 但屏幕仍是频谱，优先怀疑缺少 `cle`；
6. 若 `[7]=0` 且 `[9]=1`，优先怀疑 render/plot 请求时序。

## 6. 当前结论

| 异常 | 当前最可能原因 | 置信度 |
|---|---|---|
| 弱基波 25 mV 测成约 30 mV | 信号源波形状态、过渡帧或模拟/采集杂散 | 中 |
| 首次 500 kHz 被拆成 400 kHz/92 mV + 500 kHz/8 mV | 当次可能是非稳态 FFT 帧，但不能解释后续稳定异常 | 中 |
| 等待后 500 kHz 仅剩 0～5 mV 相干幅值 | FFT 支路帧数据失真，或 ADC 码捕获错误导致能量扩散 | 高 |
| 500 kHz 波形阶梯明显 | 40 点/周期扩展到 800 屏幕点 | 高，属预期显示现象 |
| 频谱返回时域需按两次 | render 请求丢失窗口或未 `cle` 的追加显示 | 中高 |

新的等待复测已经证明问题不只是信号源切换过快。仍不应直接修改频率插值或 Hann
幅值公式；下一步应使用包含 ADC/FIR/FFT 输入/频谱 bin 的诊断 ILA，先确定相干性
在哪一级丢失。显示平滑、render 请求保持和波形清屏属于另外一条可独立修复的显示
路径。

## 7. 2026-07-31 实施结果

本轮数字自检没有复现“Hann/插值公式因相位造成弱基波偏差”。新增的十帧测试覆盖
500 kHz 两种相位、499.5/499.9 kHz，以及 `100/200/400 kHz`、幅值码
`100/400/500`、相位 `100°/40°/0°` 的弱基波三音，频率和幅值全部通过。因此本轮
没有无依据改写幅值算法。

已发现并修复两个确定性问题：

1. 500 kHz 位于搜索上界 bin 1024，旧局部峰条件隐含要求右侧还有下降样点；现在
   最后合法 bin 可按单边条件成为峰值。
2. 时域 render 请求在空闲但前置条件尚未满足时可能丢失；现在所有忙/等待窗口都会
   锁存请求。传图前加入 `cle s0.id,0`，FE/FD 加超时回收。

同时加入两帧稳定门，避免信号源改频或开关通道后的首帧进入显示；加入只作用于显示
支路的线性插值和频谱左右留白。新的 ILA 不再重复屏幕数值，只保留
ADC/FIR/FFT 数据、FFT bin、握手和 sticky error，供下一轮板测判断真实异常最早出现
在哪一级。
